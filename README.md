สรุปงานและอธิบายการทำงานของโค้ดทั้ง 6 ข้อคับ
1. `ex1-profile.js` — แนะนำตัว
* ประกาศตัวแปรเก็บข้อมูลส่วนตัวด้วย `const` ทั้งหมด (ชื่อเล่น, รหัสนักศึกษา, อายุ, สาขา, จำนวนวิชา)
* คำนวณปีที่จะจบการศึกษาจากสูตร `2569 + จำนวนปีที่เหลือ`
* แสดงผลเป็นรูปแบบบัตรแนะนำตัวด้วย Template Literal (ใช้ backtick `` ` ``) โดยไม่ใช้เครื่องหมาย `+` ต่อสตริง

2. `ex2-types.js` — ชนิดข้อมูลและ typeof
* ส่วนที่ 1:เช็กและแสดงชนิดข้อมูล 6 ประเภท (`string`, `number`, `boolean`, `undefined`, `null`, `array`) โดยใช้ `typeof`
* ส่วนที่ 2:เช็กเคสพิเศษตามโจทย์ เช่น `typeof null` (ได้ `"object"`), ตัวแปรที่ยังไม่กำหนดค่า (ได้ `"undefined"`), และ `typeof NaN` (ได้ `"number"`)
* ส่วนที่ 3:แปลงสตริงเป็นตัวเลขด้วย `Number()`, จัดทศนิยม 1 ตำแหน่งด้วย `.toFixed(1)` และเทียบความแตกต่างระหว่างการใช้ `===` ในการเช็กประเภทข้อมูล

3. `ex3-calculator.js` — เครื่องคิดเลขคะแนน
* เก็บเกณฑ์ตัวเลขคงที่ (60, 20, 100, 80) ไว้ในตัวแปร `const` ทั้งหมด ไม่พิมพ์ตัวเลขดิบลงในสูตรคำนวณ
* คำนวณแปลงคะแนน Workshop ดิบจากเต็ม 60 ให้เป็นคะแนนเก็บเต็ม 20 ด้วยสูตร `(workshopRaw / 60) * 20`
* สรุปคะแนนรวมทั้งหมด คิดเป็นเปอร์เซ็นต์ และคำนวณคะแนนที่ยังขาดเพื่อให้ได้เป้าหมาย 80 คะแนน (ถ้าเกินจะแสดงเป็นค่าติดลบ)
* แสดงผลสรุปโดยใช้ `.toFixed(2)` คุมทศนิยม 2 ตำแหน่ง

4. `ex4-grade.js` — ตัดเกรดจากคะแนน
* สร้างฟังก์ชัน `toGrade(score)` สำหรับตัดเกรด A ถึง F
* มีระบบ Validate ข้อมูลเข้า ถ้าคะแนน < 0 หรือ > 100 จะส่งข้อความเตือนและไม่ตัดเกรดให้
* เรียงเงื่อนไข `if / else if` จากคะแนนมากไปน้อย เพื่อให้เช็กช่วงคะแนนสูงก่อน ป้องกันคะแนนมั่ว
* วนลูปทดสอบชุดข้อมูลคะแนน 13 ค่าด้วย `for...of` ครบทุกเคส

5. `ex5-switch.js` — ระบบสั่งอาหาร
* เขียนฟังก์ชัน `getMenuPrice` โดยใช้ `switch` และทำ fall-through รวมกลุ่มเมนูราคา 50 บาท (ข้าวผัด ข้าวมันไก่ ข้าวหมูแดง) ไว้ด้วยกันเพื่อลดโค้ดซ้ำ
* เขียนฟังก์ชัน `getSizeMultiplier` หาตัวคูณราคาตามไซส์ (ธรรมดา x1, พิเศษ x1.5, จัมโบ้ x2)
* มี `default` รองรับทั้งเมนูและไซส์ที่ไม่ตรงกับในรายการ
* วนลูปคำนวณราคารวมจาก `ราคาเมนู * ตัวคูณไซส์ * จำนวน` ออเดอร์ทั้งหมด 5 รายการ

 6. `ex6-login.js` — ระบบตรวจสอบสิทธิ์
* เขียนฟังก์ชัน `login` เช็กเงื่อนไขตามลำดับความสำคัญความปลอดภัย:
  1. เช็ก Username / Password ก่อนเสมอ (Authentication)
  2. เช็กสถานะบัญชี (`isActive`)
  3. เช็กอายุ (`age >= 18`)
  4. เช็กสิทธิ์ (`role`: อาจารย์ / นักศึกษา)

## Workshop 2 (ce385-week3)

ex1-functions.js
ไฟล์นี้เน้นเรื่องการเขียนฟังก์ชันคำนวณคะแนนและตัดเกรดครับ โดยปรับมาใช้ Arrow Function ทั้งหมด ใช้ isValidScore เช็คคะแนนก่อนตัดเกรดเสมอเพื่อความถูกต้อง แล้วก็เขียน toGrade ด้วยการใช้ find ร่วมกับ Array ตามที่โจทย์แนะนำ ซึ่งช่วยให้โค้ดสั้นลงมาก ไม่ต้องใช้ if-else ซ้อนกันหลายชั้น

นอกจากนี้ตรงฟังก์ชันคำนวณคะแนนเวิร์กชอป มีการตั้ง Default Parameters ไว้ และได้ลองทดสอบส่งค่า undefined เข้าไปเพื่อพิสูจน์ว่าระบบยังคงดึงค่าเริ่มต้นมาคำนวณได้ถูกต้อง ไม่เกิด Error ครับ

ex2-collection.js
ข้อนี้เป็นเรื่องการจัดการข้อมูลนักศึกษาหลายๆ คนในรูปแบบ Array of Objects ครับ เขียนฟังก์ชันค้นหาต่างๆ ทั้ง findById, findByMajor และ hasFailingStudent โดยยึดหลักว่าจะไม่ไปแก้ไข Array ต้นฉบับเลย

ในส่วนของการดึงอีเมล ได้นำ Optional Chaining (เครื่องหมาย ?.) และ Nullish Coalescing (เครื่องหมาย ??) มาช่วยจัดการกรณีที่ค้นหาไม่เจอ หรือกรณีที่นักศึกษาคนนั้นไม่มีข้อมูลติดต่อ ผลลัพธ์ที่ได้จะขึ้นข้อความแจ้งเตือนแทนที่จะเจอ Error แล้วโปรแกรมค้างครับ

ex3-transform.js
ข้อนี้ฝึกการประมวลผลข้อมูลระดับสูง โดยไม่ใช้ลูป for หรือ while เลย เปลี่ยนมาใช้เมธอด map, filter และ reduce แทนทั้งหมด เช่น การรวมคะแนน การหาค่าเฉลี่ย และการนับจำนวนเกรด

ส่วนโจทย์ที่ให้ทำท่อข้อมูลต่อกันในบรรทัดเดียว ได้ลองเขียนเชื่อม filter, map และ reduce เข้าด้วยกันเพื่อหาคะแนนเฉลี่ยของเด็ก CE ที่สอบผ่าน และได้ทำการทดสอบกรณีส่ง Array ว่างเข้าไปด้วย ผลลัพธ์ที่ได้คืนค่ากลับมาเป็น 0 ไม่เกิดปัญหา NaN ครับ

## Workshop 3 (ce385-week4)

1. `ex1-callback.js` — ระบบตรวจทะเบียน (Error-first Callback)

- สร้างฟังก์ชัน `fetchStudentById` รับ `id` และ `callback` หน่วงเวลา 300ms ด้วย `setTimeout`
- มีระบบ Validate ข้อมูลเข้า ถ้า `id` ไม่ใช่ string หรือหาไม่เจอ จะส่ง `new Error()` เข้า callback ทันที
- ถ้าพบข้อมูล จะส่ง `null` ในช่อง error และส่งวัตถุข้อมูลนักศึกษาแบบตื้น `{ ...student }`
- วนลูปทดสอบครบทั้ง 3 เคส (id มีจริง, id ไม่มีจริง, id ผิดประเภท)
- ตอบคำถามท้ายไฟล์เกี่ยวกับการอ่านค่า property โดยไม่เช็ค error และความจำเป็นของการใส่ `return`

2. `ex2-promise.js` — แปลง Callback เป็น Promise

- เขียนฟังก์ชัน `fetchStudentByIdAsync` คืนค่าเป็น `Promise` (โดยไม่ใช้คีย์เวิร์ด `async`)
- เรียกใช้งานด้วย `.then()`, `.catch()`, และ `.finally()` ครบทั้ง 3 เคส
- ทำ Promise Chain 3 ขั้น: รับข้อมูล -> คำนวณเกรด -> สร้างข้อความรายงาน -> พิมพ์ออกทาง console
- เขียนฟังก์ชัน `promisify` อเนกประสงค์สำหรับแปลงฟังก์ชันรูปแบบ callback ให้คืนค่าเป็น Promise

3. `ex3-async-await.js` — async/await และลำดับ vs ขนาน

- เปรียบเทียบการดึงข้อมูล 3 รายการแบบ sequential (ใช้ `for...of` + `await`) กับแบบ parallel (ใช้ `Promise.all` + `.map`)
- วัดเวลาการทำงานจริง พบว่าแบบขนานทำงานเร็วกว่าแบบตามลำดับประมาณ 3 เท่า
- สร้างฟังก์ชัน `safeReport` หุ้มด้วย `try-catch-finally` เพื่อจัดการ error โดยไม่ให้โปรแกรมพัง
- ตอบคำถามท้ายไฟล์เรื่องความแตกต่างระหว่าง `try-catch` กับ callback และผลกระทบจากการลืมใส่ `await` หน้า `Promise.all`

4. `ex4-combinators.js` — เลือก Combinator ให้ถูกงาน

- เลือกใช้ Promise Combinators ตามสถานการณ์ที่เหมาะสม:
  - สถานการณ์ที่ 1: หน้าแรก ใช้ `Promise.all` เพราะต้องการข้อมูลครบทุกส่วน ถ้ามีส่วนใดล้มเหลวจะเปิดไม่ได้ทันที
  - สถานการณ์ที่ 2: แจ้งเตือนผลสอบ ใช้ `Promise.allSettled` เพื่อให้ทราบสถานะทุกช่องทางโดยไม่พังตามช่องทางที่ล้มเหลว
  - สถานการณ์ที่ 3: Mirror Server ใช้ `Promise.any` เพื่อดึงข้อมูลจากเครื่องแรกที่ทำงานสำเร็จ
  - สถานการณ์ที่ 4: ค้นหาฐานข้อมูล ใช้ `Promise.race` แข่งเวลากับ timeout 800ms หากเกินเวลาจะดึงข้อมูลจากแคชเก่าแทน
